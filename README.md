# Quiz-Exam
it is a simple online quiz
Online Quiz / Exam System

A simple Python-based Online Quiz / Exam System that allows students to log in, answer multiple-choice questions, view their results, and review their answers.

Features

Student login with username and registration number

10 multiple-choice Python questions

Automatic answer checking

Score and percentage calculation

Grade calculation

Pass/Fail result

Answer review after the exam

Simple menu-driven interface

Requirements

Python 3.x

No external libraries are required.

How to Run

Save the code as quiz.py.

Open a terminal or command prompt.

Run:

python quiz.py


Enter your username and registration number.

Select Start Exam from the menu.

Answer each question using A, B, C, or D.

Grading
Percentage	Grade
90–100%	A+
80–89%	A
70–79%	B
60–69%	C
50–59%	D
Below 50%	F

A score of 40% or above is considered PASS.
